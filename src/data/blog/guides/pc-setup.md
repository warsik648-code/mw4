## What the listing requires

The product pages ask for 64-bit Windows 10 or Windows 11, a PC that already runs your game client, and a connection for checkout. They do not claim the 2007 game’s original box requirements, which belonged to older Windows versions. If the client you own does not start, fix that before you treat a cheat plan as the next step. The [shader guide](/shader-loading/) is the honest page for a long first-launch compile on newer Call of Duty PC builds, which may not be the 2007 game at all.

Call of Duty 4: Modern Warfare mobile is out of scope. There is no phone build in the store. A tablet is not a listed platform. macOS and Linux are not listed either. Play, in the sense of launching a match, still happens in the game client. This site does not launch it for you.

## Alter usually means change a setting

The query alter Call of Duty 4: Modern Warfare reads like a request to change the install: options, config files, or a class. The game’s own menus are the supported way to change video, audio, and controls. Create-a-class is how you change a multiplayer set. This article will not hand-edit a configuration to hide software or to change hardware identifiers. HWID Spoofer, if that was the real intent, is a separate monthly card, and its page still does not include a procedure.

## A macro script is not a hidden extra

Call of Duty 4: Modern Warfare macro script searches want a file that repeats inputs. The main product names No Recoil and Advanced Aimbot. It does not name a downloadable macro, and this guide will not print one. Repeating inputs can also violate a game’s terms even when no other feature is involved. If a forum offers a script beside a “season” claim, remember that this 2007 game is not on a seasonal calendar. The [patch notes guide](/patch-notes/) is the correction.

Write down the Windows edition, whether the game menu opens, and which product name you think you want. If the menu does not open, stop. A plan will not finish an installer we do not host. If the menu opens and you still want Call of Duty 4: Modern Warfare Cheats, you already know the prices and the feature names from the product page. Administrator prompts, if the delivery note mentions them, are a reason to read that note on the machine you will use. They are not a reason to disable security tools you do not understand because a comment said to. This page will not list those tools. A macro that repeats mouse movement is the same kind of omission: people search for one, and publishing one would be a procedure this site does not provide.

When the inventory is done, the remaining pages are ordinary. Status for what we will not claim. FAQ for price questions. Support email for an order that does not match the card. PC, in the URL and in the requirement, means Windows. It does not mean every desktop problem is in scope.

A second machine is a second checklist. Windows on a laptop and Windows on a desktop can both be in scope, and a phone cannot. If delivery is tied to one computer, say so in the support message instead of assuming a plan moves itself. The product pages do not promise a free machine move. They promise a Windows PC listing with the prices printed on the card you clicked.
